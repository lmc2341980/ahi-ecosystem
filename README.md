# AHI Organization

A production-ready Turborepo monorepo integrating Next.js 15, React, Tailwind CSS, FastAPI, Docker Compose, and PostgreSQL.

## Architecture

```
ahi-organization/
├── apps/
│   └── portal/              # Next.js 15 web application
├── services/
│   ├── organization/        # Organization & identity service (FastAPI)
│   ├── ai/                  # AI orchestration service (FastAPI)
│   ├── knowledge/           # Knowledge base service (FastAPI)
│   └── erp/                 # ERP aggregation service (FastAPI)
├── packages/
│   ├── shared/              # Shared types, config, and utilities
│   ├── sdk/                 # TypeScript API client SDK
│   └── ui/                  # React component library (Tailwind CSS)
└── adapters/
    ├── erpnext/             # ERPNext adapter
    ├── openwebui/           # Open WebUI adapter
    ├── n8n/                 # n8n workflow adapter
    ├── gemini/              # Google Gemini adapter
    ├── openai/              # OpenAI adapter
    └── ollama/              # Ollama adapter
```

## Prerequisites

- **Node.js** >= 20
- **pnpm** >= 9 (`corepack enable && corepack prepare pnpm@9.15.0 --activate`)
- **Python** >= 3.11
- **Docker** & **Docker Compose** (for PostgreSQL and local services)

## Getting Started

### 1. Install dependencies

```bash
pnpm install
```

### 2. Configure environment

```bash
cp .env.example .env
```

Edit `.env` with your configuration (database URL, API keys, etc.).

### 3. Start infrastructure (PostgreSQL)

```bash
docker compose up -d postgres
```

### 4. Run database migrations

```bash
pnpm --filter @ahi/organization migrate
```

### 5. Start development servers

```bash
pnpm dev
```

This starts:
- **Portal** (Next.js) on `http://localhost:3000`
- **Organization service** (FastAPI) on `http://localhost:8001`
- **AI service** (FastAPI) on `http://localhost:8002`
- **Knowledge service** (FastAPI) on `http://localhost:8003`
- **ERP service** (FastAPI) on `http://localhost:8004`

## Project Structure Details

### `packages/shared`

Shared TypeScript types, configuration schemas, and utility functions used across the frontend and SDK.

### `packages/sdk`

A typed HTTP client SDK for consuming the FastAPI services from the portal (or any TypeScript client). Generated types align with the FastAPI OpenAPI schemas.

### `packages/ui`

A React component library built with Tailwind CSS. Exports buttons, inputs, cards, layouts, and other primitives consumed by the portal.

### `apps/portal`

The main Next.js 15 (App Router) web application. Uses the shared UI package and SDK to interact with backend services.

### `services/*`

Four FastAPI microservices:
- **organization** — organizations, members, roles, and identity.
- **ai** — AI orchestration (chat, completions, embeddings) via adapter pattern.
- **knowledge** — knowledge bases, documents, and vector search.
- **erp** — ERP data aggregation and sync.

### `adapters/*`

External-system adapters following a consistent interface. Each adapter wraps a third-party API (ERPNext, Open WebUI, n8n, Gemini, OpenAI, Ollama) and exposes a normalized Python interface.
